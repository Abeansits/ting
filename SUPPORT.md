# Getting help

For usage questions and reproducible bugs, [open an issue](https://github.com/Abeansits/ting/issues/new/choose).
Include `ting --version`, your operating system, the command you ran, and the
smallest useful error excerpt. Mention which participant CLIs you use.

Before sharing logs or a forum, remove private context, credentials, and personal
information. Forums contain prompts, participant responses, and final decisions.

For contributions, see [CONTRIBUTING.md](CONTRIBUTING.md). For a vulnerability,
follow [SECURITY.md](SECURITY.md) rather than posting exploitation details publicly.

Ting is a hobby project. Responses and fixes are best effort, with no guaranteed
support schedule.
